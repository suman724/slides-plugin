# Design System Reference

## Themes

### Corporate Blue (default)
Best for: Board meetings, investor presentations, formal reviews.

| Role | Color | Hex |
|---|---|---|
| Primary | Navy | `#1B3A6B` |
| Secondary | Medium Blue | `#2E5C9E` |
| Accent | Amber | `#E8913A` |
| Accent Alt | Green | `#3A8F6E` |
| Text Primary | Near-black | `#1A1A1A` |
| Text Secondary | Dark gray | `#4A4A4A` |
| Text on Primary | White | `#FFFFFF` |
| Background | White | `#FFFFFF` |
| Background Alt | Light blue-gray | `#F0F4F8` |
| Positive | Green | `#2D8F5E` |
| Negative | Red | `#C0392B` |

### Modern Dark

| Role | Color | Hex |

## Typography

All themes use Calibri (fallback: Arial) for universal compatibility.

| Role | Size | Weight | Usage |
|---|---|---|---|
| Title Slide Title | 36pt | Bold | Title/closing slide main text |
| Title Slide Subtitle | 18pt | Regular | Title/closing slide secondary text |
| Slide Title | 28pt | Bold | Standard slide titles |
| Section Title | 36pt | Bold | Section divider titles |
| Heading | 20pt | Bold | Column headers, card titles |
| Body | 14pt | Regular | Bullet text, body copy |
| Body Small | 12pt | Regular | Sub-bullets, annotations |
| Caption | 10pt | Regular | Footnotes, chart annotations |
| Metric Value | 40pt | Bold | KPI card values |
| Metric Label | 12pt | Regular | KPI card labels |
| Metric Delta | 14pt | Bold | KPI change indicators |
| Footer | 8pt | Regular | Footer text, page numbers |

## Grid System

Widescreen 16:9 format (13.333" x 7.5"):

```
Margins:       left=0.75"  right=0.75"  top=0.40"  bottom=0.60"
Content area:  11.833" wide
Title bar:     0.80" height (from top margin)
Content top:   1.40" from slide top
Footer bar:    0.35" height
Column gutter: 0.40"
```

## Decorative Elements

- **Accent bar:** 4px colored line (accent color) under slide titles
- **Title slide:** Vertical accent stripe on left side
- **Section divider:** Full-height primary-colored left band
- **Footer:** Thin separator line above footer area
- **KPI cards:** Rounded rectangles with background_alt fill
- **Table headers:** Primary color background, white text
- **Table rows:** Alternating white and background_alt
- **Comparison cards:** Rounded rectangles with background_alt fill
- **Timeline:** Horizontal connector line with accent-colored circle markers
